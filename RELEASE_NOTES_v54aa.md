# My Life Planner v54aa — Timeline Appointment Delete

Built from the user-confirmed v54x stable baseline. Project Templates work from v54y/v54z has been abandoned and is not included.

## One functional change
When an existing appointment is opened for editing — including from Timeline / Next 7 Days — the dialog now includes **Delete**. This lets an accidental duplicate be removed without going to Lists.

Delete is hidden when creating a new appointment. For a repeating appointment, the confirmation explicitly states that the repeating appointment and all occurrences will be removed.

## Deliberately unchanged
To-do and Project Pending, recurring completion/undo, project-step undo/reordering, ordinary to-do undo, Today timed appointment priority, iPhone portrait menu repairs, backup/restore and PWA update behaviour.

v54aa remains a test build until user acceptance.
