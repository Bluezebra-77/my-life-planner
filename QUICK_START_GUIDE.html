First Use & Quick Start

Development v54bo · Blue Zebra 77

Keep the first setup simple

You do not need to fill every part of the planner. Set up the pieces you will actually use, then add more as you become familiar with it.

1. Personalise the planner

  1. Open Settings.
  2. Add your preferred name if you want personalised greetings.
  3. Choose any appearance or display preferences you want to change.

2. Set up Daily Rhythm

On Home, open Daily Rhythm and use its menu to add or edit the small routine steps that help structure your morning or afternoon.

3. Set up Evening Routine

Add the close-down steps that are useful to you. Keep this short; it is intended as a gentle routine rather than another long task list.

4. Add your first To-do

Use the blue + Quick Add button and choose To-do. Add a due date only when the item genuinely needs one.

5. Try Today’s Focus

Add one or two practical actions you want visible today.

6. Create a recurring responsibility

Create a Recurring Task, choose its first due date and recurrence. It stays due until completed and then advances.

7. Create a list that is yours

In Lists, create a Custom List - for example Things to buy, Books to read or Holiday packing. Completed items can be unticked again.

8. Use Brain Inbox when you are unsure

If you need to capture something but do not yet know whether it is a task, project or appointment, put it in Brain Inbox. You can convert it later.

9. Know where to look

  • Home - what needs your attention now.
  • Lists - complete collections and editing.
  • Timeline - date-based planning.
  • Settings - customisation, backup, help and maintenance.

10. Make a backup

After setup, open Settings → Backup and restore and create a manual export. Repeat this regularly and before important updates.

That is enough to begin

Projects, Pending, annual dates, cleaning schedules, timers and the other tools can be explored when you need them.

For more detail, open the Help Centre.
