# My Life Planner v54ak — Consolidated Pending

Built from user-confirmed v54aj. The former Waiting For view is presented as **Pending** and now consolidates active Pending ordinary to-dos, active Pending project steps, and existing standalone Waiting For records (shown as Pending notes). Original to-dos/project steps remain in their own lists; no data is moved or duplicated. The underlying `waiting` data key is retained for backwards-compatible storage and backups.

Existing three-dot Pending behaviour is unchanged: Mark pending → optional reason → Mark active.
