Settings

Five daily backups

The planner keeps one dated copy for each of the latest five days. Each day's copy is refreshed whenever you save, so it contains the latest state from that day.

Where can I find my backups?

Automatic daily backups: Settings → Five daily backups. They are stored privately inside Safari on this device and are not visible in the Files app.

Backups you can see: tap Save backup file or Share backup, then choose Save to Files and select iCloud Drive or OneDrive.
