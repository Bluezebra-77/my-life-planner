# My Life Planner v54aq — Brain Inbox Image Integrity

Built from v54ap.

Brain Inbox image/document previews are directly openable. When a Brain Inbox item is converted to a Project, its attachment is copied into the Project, preserved through later Project edits, and shown/openable in the Project edit screen. The existing attachment viewer is reused.

The v54ap IndexedDB automatic-recovery block is unchanged.
