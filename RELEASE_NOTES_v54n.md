# My Life Planner v54n — Birthday Rollover Fix

- Birthday/annual-date editing no longer displays the artificial year 2000.
- The date field now opens on the next real occurrence.
- If this year’s birthday has passed, the next occurrence automatically becomes next year.
- The default reminder remains 7 days before and can still be changed.
- Optional birth year can be stored separately for age information.
- Annual-date lists now display the full next occurrence including year.
- Existing annual-date records remain compatible; no storage key changes.
- v54m recurring completion logic is preserved unchanged.
