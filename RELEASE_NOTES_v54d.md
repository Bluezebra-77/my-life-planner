# My Life Planner v54d — Recurring Workflow Patch

## Changes
- Restores true complete-and-advance behaviour for recurring tasks from Home → Today and Home → Recurring Tasks.
- The completion circle now acts immediately; the current occurrence disappears when completed.
- Daily, every-N-days, weekly and monthly recurrence continue to use the existing recurrence engine and end rules.
- Home Today, Recurring Tasks, This Week and Timeline are explicitly refreshed after an occurrence advances.
- A saved confirmation reports the new next-due date, or confirms that a limited recurrence has finished.
- The recurring three-dot menu is reserved for management (Edit/Pause); completion uses the circle.
- Home Show all / Show less controls are lighter and more compact.

## Preserved
Project Templates, Smart Projects, dated steps in Timeline, Cleaning by Area, advanced monthly recurrence, recurrence end rules, Brain Inbox expansion, Daily Rhythm, Evening Routine and all existing saved planner data.
