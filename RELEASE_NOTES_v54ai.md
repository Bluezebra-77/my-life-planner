# My Life Planner v54ai — Pending Menu Consistency

Built from v54ah. Removes the later inline Pending checkbox/circle from Home and Lists. Pending returns to the established three-dot menu workflow for ordinary to-dos and project steps: Mark pending prompts for an optional reason; Pending/reason is shown in item metadata; the menu then offers Mark active. No Today/Needs Attention data-source, recurring, Timeline, or update-system behaviour was changed.
