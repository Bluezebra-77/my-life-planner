# v54ai Regression Checklist

## Pending interaction
- Ordinary to-do: ⋯ menu shows Mark pending; selecting it prompts for optional reason.
- Pending ordinary to-do displays Pending and reason in Home/List metadata where shown; ⋯ changes to Mark active.
- Project step: ⋯ menu shows Mark pending; selecting it prompts for optional reason.
- Pending project step displays Pending and reason; ⋯ changes to Mark active.
- No second Pending checkbox/circle is displayed on Home cards or List rows.
- Desktop and 390px iPhone-width layouts use the same menu-based interaction.

## Protected behaviour
- Today — Time Sensitive remains populated on iPhone and desktop.
- Needs Attention remains populated on iPhone and desktop.
- Due/overdue Pending to-dos/project steps still surface in Today and Needs Attention.
- Overdue Pending items remain red and show OVERDUE.
- Project Next step continues to skip Pending steps.
- Portrait three-dot menus stay inside the viewport.
- Recurring completion/Undo, Timeline Delete and timed appointment ordering remain unchanged.
- Desktop/iPhone updater remains the v54ah repaired version-addressed update mechanism.
