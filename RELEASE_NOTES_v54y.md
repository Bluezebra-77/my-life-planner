# My Life Planner v54y — Project Templates Phase 1

Built from the user-confirmed v54x baseline.

## One functional change
Project Templates Phase 1 makes saved templates a supported planner-data feature. Existing projects can be saved as reusable templates, preserving step names/order without copying completion state. Templates can be edited or deleted. Template data is stored inside the main planner data so Backup / Export and Restore / Import include it.

Creating a new project from a saved template is deliberately deferred to Phase 2.
