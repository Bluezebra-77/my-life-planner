# My Life Planner v54tR1 — Today Completed Appointment Sort Repair

## One functional change
In Home → Today — Time Sensitive, ticking an appointment leaves it visible for the rest of today but immediately moves that row below all currently outstanding rows.

This is a display/order repair only. It does not add appointment completion persistence, alter appointment recurrence, change recurring-task completion, or implement timed-item prioritisation.

## Baseline
Built directly from the user-confirmed v54sR2 baseline. v54sR2 remains the fallback stable build until v54tR1 is user-tested and accepted.
