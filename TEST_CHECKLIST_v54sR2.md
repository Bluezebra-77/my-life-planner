# v54sR2 Test Checklist

## Focused iPhone portrait repair
- Open Lists → To-dos in portrait.
- Confirm the three-dot menu is visible on ordinary to-do rows without rotating the phone.
- If a to-do has steps, confirm the three-dot menu is visible on each indented step.
- Open several menus and confirm Complete / Mark incomplete, Edit, and Delete actions still work as applicable.
- Rotate portrait → landscape → portrait and confirm the controls remain visible.

## Regression checks
- Lists → Projects: project and project-step three-dot menus remain visible in portrait.
- Ordinary to-do Mark incomplete still reverses completion and clears its completion activity/statistics record.
- Project-step Mark incomplete still works.
- Recurring task: tapping completion advances the current occurrence correctly and refreshes views.
- Recurring three-dot management menu remains available.
- Home Global Timer remains available.
- Birthday / Anniversary Quick Add remains available.
- Existing data, backup/export and restore/import remain intact.

Do not accept v54sR2 as the stable baseline until these checks pass on the user's devices.
