# v54r — Undo Project Step Completion

One functional change only.

- Completed project steps now show **Mark incomplete** rather than Mark active.
- Reopening a completed project step clears its completion timestamp.
- The matching project-step completion activity record is removed so Evening Reflection and Hidden Statistics do not continue counting an accidental completion.
- Project ordering, dates, recurrence, Home Timer, birthdays and all other workflows are unchanged.
