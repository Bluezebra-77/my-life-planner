# My Life Planner v54ab — Timeline Delete for All Items

One functional change from accepted v54aa: every existing item opened from Timeline now exposes a direct Delete action in its edit dialog.

Covered Timeline types: appointments, to-dos, to-do steps, project steps, project deadlines, cleaning tasks, recurring tasks, birthdays/annual dates, and Waiting For items.

Deletion targets the exact Timeline item. Deleting a step deletes only the step; deleting a project deadline deletes the whole project; deleting a recurring task removes the recurring task and warns that it is not just one occurrence.

All previously accepted v54aa behaviour is retained.
