# v54t — Today completed appointment to bottom

Test build based on the user-confirmed v54sR2 baseline.

## One functional change
In **Home → Today — Time Sensitive**, ticking an appointment now moves that appointment row to the bottom of the section while leaving it visible for the rest of the current view/day.

This deliberately does **not** add appointment-time display or timed-item prioritisation. Those remain review ideas for a later build.

## Protected behaviour
- v54sR2 iPhone portrait three-dot repairs for Lists → Projects and Lists → To-dos are retained.
- Project-step Mark incomplete and ordinary to-do Mark incomplete are unchanged.
- Recurring-task completion code is unchanged.
- Existing PWA update/cache behaviour is retained.

v54t remains a test build until user acceptance.
