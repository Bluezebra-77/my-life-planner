# v54ay — Today’s Progress

Built from confirmed v54ax.

Progress now counts only today-relevant actionable work: due/overdue ordinary To-dos, Today’s Focus, due/overdue project steps, and due/overdue recurring tasks. Pending items, appointments, routines, future work and undated general To-dos are excluded. Completed-today eligible items remain in the denominator. The display is shown by default and can be hidden/re-shown.
