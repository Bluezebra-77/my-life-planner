# My Life Planner v54z — Project Templates Phase 2

One functional change from v54yR2: a saved Project Template can now be used to create a fresh independent project.

- Choose **Use template** from Project Templates.
- Enter the new project's name and, optionally, its due date and notes.
- Template steps are copied in the saved order.
- Steps with a saved "days before" offset receive dates calculated back from the new project due date.
- The new project and all copied steps start incomplete and Active (not Pending).
- Editing or completing the new project does not alter the template.

No changes were made to recurring-task completion/undo, ordinary to-do Pending/undo, project-step Pending/undo, Waiting For, Timeline, or iPhone portrait menu behaviour.
